## Why Git Makes Development Easier

Regarding security, Git makes it easy to save a copy of the work and
 go back to it anytime without the fear of losing it after any code
 alteration. About tracking, Git notes every movement and logs all
 details: what changed, when it changed, and who did it. Also, it
 helps in team collaboration. It allows all programmers to
 work on their own paths and share their work with
 each other; then they can easily merge their work.
